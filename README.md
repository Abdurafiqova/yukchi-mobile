# YUKCHI.UZ — mobile app

Expo / React Native haydovchi ilovasi: yuk tasniflari tasmasi, yo'nalishlar, chat, hujjatlar va valyuta kurslari. Interfeys o'zbek / rus / ingliz tillarida.

## Ishga tushirish

```bash
npm install
EXPO_PUBLIC_API_URL=http://localhost:4000/api/v1 npx expo start
```

API sozlamasi: [yukchi-api](https://github.com/Abdurafiqova/yukchi-api)
